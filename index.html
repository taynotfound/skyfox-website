Built for looking up

The useful parts of flight tracking, kept close.

01 / LIVE MAP

See what is moving now.

Track aircraft on a clear live map with selectable layers, location controls, refresh, filters, and a focused detail view.

◌

02 / SEARCH

Find the one you saw.

Search by HEX code, callsign, registration, airframe, or SQUAWK and jump from a result to its details.

03 / WATCHLISTS

Keep an eye on favourites.

Watch aircraft, ICAO addresses, callsigns, registrations, and SQUAWKs with alert support.

04 / PLANE DETAILS

Know what is overhead.

Open a full aircraft profile with registration, operator, route, live flight data, registry details, and emergency squawk alerts.

Open, independent, honest

Built in public.
Clear about what it is.

SkyFox is an independent project based on the airplanes.live Android app. It uses airplanes.live data and is not affiliated with or endorsed by airplanes.live.

It is maintained by Tay März. Read the code, inspect the builds, or help make the next release better.
