FAQ

Good to know.

What is SkyFox?

SkyFox is a free, open-source Android app for live aircraft tracking using ADS-B data from airplanes.live.

Do I need an account?

No. You can install SkyFox and start using it without creating an account.

Where does the aircraft data come from?

Aircraft data is provided by airplanes.live, a community-driven ADS-B network. SkyFox is independent and is not affiliated with or endorsed by airplanes.live.

Why does SkyFox need location permission?

Location is used to show aircraft near you and center the map. You can decline permission and move the map manually instead.

Is SkyFox available on iOS?

No. SkyFox is currently Android-only.

Independent project

Open about what SkyFox is.

SkyFox is based on the airplanes.live Android app by d4rken (GPL). Aircraft data is provided by airplanes.live. SkyFox is independent and not affiliated with or endorsed by airplanes.live. AI tools were used during development for brainstorming, UI exploration, documentation, repetitive coding and debugging; final decisions, testing and claims remain the maintainer’s responsibility.
